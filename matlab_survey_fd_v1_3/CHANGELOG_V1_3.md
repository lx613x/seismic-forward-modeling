# V1.3 更新记录（相对 V1.2）

## 物理模型及数值处理

1. 在 `semblance_scan.m` 和 `nmo_stack.m` 中加入震源子波中心延迟 `sourceDelay`，采用 `t_in = ts + sqrt((t_out - ts)^2 + (offset/v)^2)` 的教学型双曲线校正关系。
2. NMO现在同时返回平均叠加道和完整的NMO校正后道集，越界插值使用 `NaN` 标明无效数据；没有添加拉伸切除。
3. `quality_metrics.m` 将相同的延迟用于清洁/含噪道集，并存储用于绘图的NMO后道集。
4. 在 `default_config.m` 新增 `cfg.snapshotShotX`（默认模型中心 1000 m），与A/B/C/D观测系统完全独立。
5. 新增 `save_center_snapshots.m`，从模型中心震源单独计算四个时刻的波场快照；其缓存校验包括完整速度矩阵、网格、源参数和快照时间。原先以第一炮为快照震源的逻辑已移除。

## 绘图及使用

1. 仍保持 **一个图形窗口，每张图一个标签页**；现共有10个标签页。
2. 添加“速度扫描”“NMO校正后”标签；原始CMP增加简化理论走时虚线，NMO叠加标注反射参考时间。
3. 速度模型标注用于快照的中心炮；不改变评价用炮检几何。
4. 每个标签仍单独导出PNG，文件名已更新为 `01_...` 至 `10_...`。

## 测试与结果

- `tests/run_tests.m` 加入有已知速度（2000 m/s）、已知震源延迟（0.10 s）的理想双曲线合成检验，以及小型中心炮快照与缓存回归测试。
- `tests/test_plot_tabs.m` 测试10个标签及三项新增PNG输出。
- 新增 `noise_repeat_test.m`，复用正演炮集，重复不同噪声种子，以平均分、标准差和胜出次数衡量评分稳定性；输出CSV，不弹额外图窗。
- 本版未改变基本波动方程解算器、采集候选方案、几何硬约束和评分权重；修改后质量指标及最优方案**可能改变**，应重新验证。

## 适用边界

- 此版本仍是**二维常密度声学正演教学/研究原型**，不是生产级地震成像软件。
- 相干速度扫描是指定时间窗下的一维速度评分曲线；双曲线NMO在起伏界面和复杂速度场中仅是近似。有限差分震源延迟与反射时间窗的关系仍需要结合模型走时检查。
- 当前未加入初至切除、NMO拉伸切除或复杂构造偏移成像；后续应做专门验证，不应据此声称目标层成像质量提高。
- 当前环境无MATLAB运行许可，已完成静态审查及Python数值对照，但仍需在MATLAB R2025b上运行 `run_tests` 与 `test_plot_tabs`。
