# 本交付版本的验证状态

## 已完成（无需 MATLAB 的检查）

- MATLAB 函数文件名与函数名一致；脚本使用基本 MATLAB 数组函数与控制流。
- 采用 Python 独立重算几何覆盖：quick 方案 A/B/C/D 的最低覆盖次数依次为 6/7/7/7；最低合格绝对炮检距种类为 2/3/3/2；B、C 合格。
- 同一几何公式在 full 模式下，A/B/C/D 最低覆盖次数分别为 5/6/6/6；最低合格绝对炮检距种类为 2/3/3/2；B、C 合格。
- 成本在 quick 模式下 B=65125、C=69585；full 模式 B=140495、C=144975（均为教学成本单位）。这只是单项成本对比，不预判实测综合评分的赢家。
- 空间四阶离散、时间二阶离散与阻尼更新公式逐项检查；CFL限制为保守 `dt * vmax / dx < 0.45`。
- 使用单独的物理区域与外部 sponge 扩展层，不把负坐标检波器直接放入阻尼层。
- 含噪正演数据与无噪声正演数据共享同一组炮点和物理参数；随机种子固定；重复跑配置成本/权重可以加载缓存。
